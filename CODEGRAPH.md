## 1. Overview

| | |
|---|---|
| What | Desktop RSS/Atom reader with folders, in-app article view with images, manual HTTP/SOCKS5 proxy toggle, reader font controls |

## 2. Architecture

```
main()
 └─ MainWindow (QMainWindow)                      owns ALL state + network manager
     ├─ self.nam  QNetworkAccessManager           the ONLY network manager (proxy lives here)
     ├─ self.tree  FeedTree (QTreeWidget)         "All Feeds" / folders / feeds
     ├─ self.article_list  QListWidget            rows drawn by ArticleDelegate
     └─ self.browser  ArticleBrowser (QTextBrowser)   article HTML + image downloading (shares self.nam)

Dialogs (modal, stateless): ProxyDialog, AddFeedDialog, EditFeedDialog
Helpers (module level): enum_value, themed, apply_timeout, prepare_request, media_image, strip_img_size
```

Layout: `QSplitter` with three panes: tree | article list | browser. Toolbar built in `_build_toolbar`.

## 4. Data model

### In-memory state (all on `MainWindow`)
| Attribute | Type | Meaning |
|---|---|---|
| `feeds` | `list[dict]` | subscriptions, order = display order |
| `folders` | `list[str]` | folder names, order = display order, names unique (case-insensitive) |
| `collapsed` | `set[str]` | folder names the user collapsed |
| `entries` | `dict[url, list[entry]]` | fetched articles, **memory only** |
| `current_items` | `list[entry]` | what the article list currently shows (row index → entry) |

### Feed dict
```python
{"url": str,            # identity key everywhere
 "title": str,          # auto-filled from feed on fetch (url until then)
 "folder": str,         # "" = no folder; otherwise must exist in self.folders
 "custom_title": bool}  # True = user-set name; fetch must not overwrite it (may be missing in old data → treat as False)
```

### Entry dict (built in `_on_finished`)
```python
{"title", "link", "date_str", "ts" (epoch int, 0 if undated),
 "html" (body), "feed_url", "feed_title"}
```

## 5. Key flows

**Startup:** `__init__` → `_build_ui` → `_build_toolbar` → `_load_data` → `_load_reader_font` → `_apply_proxy` → `_restore_window_state` → `_rebuild_tree(select=("all",""))` → `refresh_all`.

**Fetch a feed:** `_fetch(url)` (uses `prepare_request`) → `_on_finished` → `feedparser.parse` → update `feed["title"]` (unless `custom_title`) and the tree item text → build entry dicts → `self.entries[url]` → if `url in _urls_for_selection()` then `_populate_articles(preserve=True)`.

**Select in tree:** `currentItemChanged` → `_on_tree_changed` → toggles Edit/Delete actions → `_populate_articles(preserve=False)` (clears the browser). Selection kinds: `"all"` (every feed), `"folder"` (feeds in that folder), `"feed"`. Multi-feed views are sorted by `ts` descending.

**Open an article:** `article_list.currentRowChanged` → `_show_article` → `browser.show_entry(entry)` → `_render`. `<img>` tags trigger `loadResource` → async `_fetch_image` → `_image_done` → `addResource` → debounced `_render`.

**Folder/feed mutation** (`new_folder`, `_rename_folder`, `_delete_folder`, `_delete_feed`, `_move_feed`, `_add_feed_dialog`, `_edit_feed`): mutate `self.feeds`/`self.folders` → `_save_data()` → `_rebuild_tree(select=...)`. Follow this pattern for any new mutation.

**Drag & drop:** `FeedTree.dropEvent` → `feed_dropped` → `QTimer.singleShot(0, ...)` → `_move_feed`.

**Proxy:** toggle/dialog → `_apply_proxy` sets `self.nam.setProxy(...)` (`NoProxy` when off). Feeds and images both use `self.nam`.

## 6. Gotchas and invariants (read before editing)

1. **Always `prepare_request(req)`** for any new `QNetworkRequest`. It disables HTTP/2; Qt's HTTP/2 client fails with GOAWAY errors when many image requests hit one host.
2. **Never create another `QNetworkAccessManager`.** The proxy is set only on `self.nam`; a second manager silently bypasses it. Pass `self.nam` along (as `ArticleBrowser` does).
3. **Slots connected to `QAction.triggered` must not have optional parameters**: Qt passes the `checked` bool into them. Use a no-arg public slot that calls a parameterized private method (`add_feed()` → `_add_feed_dialog(folder)`), or a lambda.
4. **Tree item identity** is `(ROLE_KIND, ROLE_KEY)`; for feeds the key is the URL, so changing a URL means rebuilding the tree and re-selecting by the new key (`_edit_feed` does this).
5. **`_rebuild_tree` blocks signals while building**, then `_select_key` calls `setCurrentItem`, which fires `_on_tree_changed` → article list reset. Don't expect article-pane state to survive a rebuild.
6. **`FeedTree.dropEvent` must end with `IgnoreAction` + `accept()`**, otherwise Qt deletes the dragged source item after a "move". The actual move is deferred with `QTimer.singleShot(0)` so the tree isn't rebuilt mid-drag.
7. **`_populate_articles(preserve=True)`** keeps the open article (matched by `link`) and the list scroll position; `preserve=False` clears the browser.
8. **Folders are plain name strings.** Renaming must update `self.folders`, every `feed["folder"]`, and `self.collapsed`. Deleting offers "keep feeds" (set `folder=""`) or "delete feeds too".
9. **Titles:** `_on_finished` overwrites `feed["title"]` only when `custom_title` is falsy. Cached entries carry their own `feed_title`; update them if the title changes without a refetch (`_edit_feed` does).
10. **QTextBrowser = Qt rich text subset, not a browser.** No class selectors in the default stylesheet (use inline styles for one-offs), sizes in `pt`/`px`, no `max-width`, no JS/iframes. Set stylesheet/font on the document **before** `setHtml`.
11. **Image loading:** `loadResource` must return immediately (placeholder), downloads are async, and `document().addResource()` takes priority over Qt's internal cache, which is why it's used after each download. Reload is debounced; don't call `setHtml` per image.
12. **Legacy name:** `self.act_rename` is the toolbar "Edit" action (edits feeds, renames folders). Kept to avoid churn.
13. **Cross-version PySide6:** use `enum_value()` for enum→int, and `apply_timeout()` for timeouts. `QFontDialog.getFont` return order is handled in `choose_font`.
14. **Desktop integration:** `app.setDesktopFileName("simple-rss")` must match `simple-rss.desktop` written by `install.sh`. The launcher runs the *installed copy*, so users must re-run `bash install.sh` after code changes.
15. The proxy password is stored in plain text in the settings file (known; KWallet would be the upgrade).

## 7. Where to change things (recipes)

| Goal | Touch |
|---|---|
| New toolbar action | `_build_toolbar`: use the local `act(text, icon_names, slot, shortcut, tip)` helper (mind gotcha 3) |
| New persisted setting | choose a `group/name` key; read in `_load_data` (or a dedicated loader), write via `settings.setValue`; update table in section 4 |
| New field on a feed | add default in `_load_data` normalization (use `.get` so old data loads), the dict in `_add_feed_dialog`, `EditFeedDialog`, and `_edit_feed` |
| New dialog | copy `AddFeedDialog` (QFormLayout + QDialogButtonBox + `values()`) |
| Unread tracking | persist read links per feed (JSON setting); mark in `_show_article`; add a new role (e.g. `0x103`) set in `_populate_articles`; bold it in `ArticleDelegate.paint`; optional counts in `_make_item` text |
| Article caching | serialize `self.entries` to `~/.cache/simple-rss/` in `_on_finished`; load before `refresh_all` in `__init__` |
| OPML import/export | new methods on `MainWindow` using `xml.etree.ElementTree`; folders ↔ outline groups; reuse the mutation pattern (modify → `_save_data` → `_rebuild_tree` → `_fetch`) |
| Auto-refresh | `QTimer` in `__init__` calling `refresh_all` (+ a setting for the interval) |
| Search/filter articles | filter `items` inside `_populate_articles` |
| Change article look | `ArticleBrowser._css`, `_build_html`, `MAX_COLUMN`; row look: `ArticleDelegate.paint` |
| Rich web rendering | swap `ArticleBrowser` for `QWebEngineView` (heavy dependency; the proxy then needs separate handling, since `self.nam` is no longer used for page loads) |
| New context-menu items | `_tree_menu` (branches on `kind`: `folder` / `feed` / `all` / empty area) |

2. Run it: `python3 simple_rss.py` and exercise the changed path
3. `bash install.sh` to update the launcher copy
4. `python3 update_codegraph.py` to refresh sections 3 and 4. It lists new symbols that need a description (search this file for `_TODO: describe_`) and symbols that were removed. `python3 update_codegraph.py --check` exits 1 if the file is stale (usable in a git pre-commit hook).
